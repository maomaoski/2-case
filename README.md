# GeoRent AI — Сервис умного подбора квартир и аналитики городской среды

Полнофункциональный бэкенд на Python (**FastAPI + SQLAlchemy 2.0 + BeautifulSoup4**) и веб-приложение (**React 19 + TypeScript + Express Gateway**) для поиска и сравнения жилья (аренда и покупка), парсинга реальных объявлений с **Авито**, нормализации запросов на естественном языке через **Google Gemini API**, анализа **Генерального плана Красноярска (admkrsk.ru)**, расчета **Семейной льготной ипотеки (6%)** и открытых государственных данных РФ.

---

## 1. Архитектура и принцип работы системы

Проект спроектирован по модульной сервисной архитектуре, где бэкенд полностью отвязан от фронтенда и может обслуживать любые сторонние клиенты:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      КЛИЕНТСКИЙ УРОВЕНЬ (FRONTEND)                          │
│  - React 19 SPA (поиск на естественном языке, фильтры, карточки, тиндер)     │
│  - Интерактивная карта Яндекс Карт (API 2.1) с точными балунами и геометками│
│  - Вкладка сравнения с эталонной квартирой                                   │
│  - Личный кабинет, регистрация и социальный поиск (совместный выбор)         │
│  * МОЖЕТ БЫТЬ ПОЛНОСТЬЮ ЗАМЕНЕН НА ЛЮБОЙ СТОРОННИЙ ФРОНТЕНД                 │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ HTTP / JSON
┌──────────────────────────────────────▼──────────────────────────────────────┐
│                    NODE.JS GATEWAY & SSR DEV SERVER (server.ts)             │
│  - Порт 3000: раздача интерфейса и проксирование API                         │
│  - Node-клиент @google/genai (Gemini 3.8 Flash)                              │
│  - Кэш градостроительных данных (Генплан admkrsk.ru, ипотека Домклик)        │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ REST API (Порт 8000)
┌──────────────────────────────────────▼──────────────────────────────────────┐
│                   PYTHON FASTAPI BACKEND (backend_fastapi/)                 │
│  ├── main.py — REST API эндпоинты (OpenAPI/Swagger на /docs)                │
│  ├── parsers/avito_parser.py — Анализатор HTML и краулер объявлений Авито   │
│  ├── parsers/real_sources_parser.py — Парсер генплана и фин. калькулятор    │
│  ├── gemini_proxy.py — Proxy-слой для Google Gemini API (работа из РФ)      │
│  ├── models.py — SQLAlchemy 2.0 ORM модели таблиц БД                        │
│  └── schemas.py — Pydantic v2 схемы валидации DTO                           │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Как работает парсер и анализатор HTML (`avito_parser.py`):
1. **Запрос и заголовки**: Парсер использует ваши точные ссылки и заголовки браузера Mozilla macOS (`st_useragent`, `st_accept`).
2. **Анализ HTML-структуры**:
   - Извлекает контейнеры `div[data-marker="item"]` или `div.iva-item-root`.
   - Если разметка фрагментирована, срабатывает резервный анализатор ссылок по регулярным выражениям вида `href="(/[^"'\s]+/kvartiry/[^"'\s]+_(\d+))"`.
3. **Формирование честной ссылки**: относительный путь `/krasnoyarsk/kvartiry/...` преобразуется в абсолютный `https://www.avito.ru/krasnoyarsk/kvartiry/...`.
4. **Анализ описания**: текст извлекается из блока `bottomBlock p` или `meta[itemprop="description"]`.
5. **Геокодирование и расстановка по карте**:
   - Функция `resolve_coordinates()` анализирует адрес объявления (улицы *Ольховая*, *Машиностроителей*, *Дудинская*, *Телевизорный пер.*, *Киренского*, *78 Добровольческой Бригады*, *Свободный*, *Молокова*, *Караульная*, *Пихтовая*, *Авиаторов*).
   - Точные географические координаты передаются на Яндекс Карту с центрированием на реальный дом.

## 3. Анализ заглушек (Stubs) и как сделать их полностью боевыми

В коде реализованы интеллектуальные фоллбэки (graceful degradation), чтобы система не падала при отсутствии ключей или блокировках:

| Блок / Механизм | Файл | Как работает сейчас (заглушка/фоллбэк) | Как перевести в 100% боевой режим |
|---|---|---|---|
| **Gemini AI API** | `gemini_proxy.py` и `server.ts` | Если `GEMINI_API_KEY` не задан, работает встроенный эвристический парсер ключевых слов и намерений (регэкспы для цен, комнат, школ, метро). | 1. Получить ключ в Google AI Studio.<br>2. Прописать в `.env`: `GEMINI_API_KEY=AIzaSy...`.<br>3. Для работы из РФ без VPN указать `GEMINI_PROXY_BASE_URL=https://api.proxyapi.ru/google/v1beta` или свой реверс-прокси на Cloudflare/Nginx. |
| **Антибот/WAF Авито** | `parsers/avito_parser.py` | С домашнего интернета и macOS парсер скачивает HTML вживую. Если Авито отдает капчу или IP заблокирован (датацентр), парсер мгновенно подключает верифицированную базу объявлений с реальными ссылками. | В продакшене для парсинга сотен страниц указать резидентный прокси в `.env`: `AVITO_PROXY_URL=http://user:pass@proxy.provider:port`. |
| **База данных** | `models.py` и `main.py` | В демо-режиме используется быстрый in-memory репозиторий списков. При этом в `models.py` уже написаны полноценные схемы SQLAlchemy 2.0. | В `main.py` раскомментировать строку `engine = create_engine(os.getenv("DATABASE_URL"))` и передать строку подключения PostgreSQL (`postgresql+psycopg2://user:pass@localhost:5432/georent`). |
| **Официальный генплан** | `parsers/real_sources_parser.py` | Делает прямой HTTP-запрос к `admkrsk.ru` и валидирует Решение Красноярского городского Совета № В-269. | Работает вживую с официальным сайтом. |
| **Льготная ипотека** | `parsers/real_sources_parser.py` | Содержит актуальные параметры Семейной ипотеки (6%, лимит 6 млн для Красноярска, 12 млн для Москвы/СПб). | Для динамических ставок можно подключить API Домклик/СберБанк. |

## 4. Пошаговый гайд: Развертывание локально на macOS

Если вы прямо сейчас скачиваете проект на MacBook / Mac:

### Шаг 0. Требования к системе
Убедитесь, что установлены Python 3.10+ и Node.js 18+. Проверить в терминале macOS:
```bash
python3 --version   # Должно быть Python 3.10 или выше
node -v             # Должно быть v18 или выше
```
*(Если чего-то нет, установите через Homebrew: `brew install python node`)*.

---

### Шаг 1. Развертывание Python FastAPI бэкенда (Терминал 1)

1. Откройте окно Terminal и перейдите в папку проекта:
```bash
cd /путь_к_проекту/backend_fastapi
```

2. Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Запустите бэкенд:
```bash
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
*Вы увидите:*
```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

5. **Проверка в браузере:**
- Документация Swagger UI: откройте `http://127.0.0.1:8000/docs`
- Проверка объявлений: `http://127.0.0.1:8000/api/listings?city=Красноярск`

---

### Шаг 2. Запуск парсера отдельно в консоли macOS

Вы можете протестировать парсер как отдельный скрипт:
```bash
# В терминале с активированным venv:
python3 parsers/avito_parser.py --city Красноярск --deal rent
```
Скрипт выведет в консоль список всех 11 квартир с кликабельными ссылками на Авито, ценами и адресами.

Также можно распарсить любой сохраненный файл HTML:
```bash
python3 parsers/avito_parser.py --file page.html --city Красноярск
```

---

### Шаг 3. Запуск фронтенда и Node Gateway (Терминал 2)

Откройте **вторую** вкладку терминала macOS в корне проекта:
```bash
cd /путь_к_проекту
npm install
npm run dev
```

Откройте в браузере Safari или Chrome:
👉 **`http://localhost:3000`**

### Что продемонстрировать:
1. **Поиск и фильтры**: введите в чат *"хочу снять квартиру на взлетке до 35 тысяч"* — система отфильтрует нужные объекты.
2. **Яндекс Карту**: нажмите на метки на карте Красноярска — откроются реальные адреса (ул. Ольховая, Машиностроителей, Дудинская, Киренского).
3. **Прямые ссылки**: нажмите «Перейти на Авито» в карточке — откроется реальная страница квартиры на Авито.
4. **Тиндер квартир**: перейдите во вкладку «Тиндер квартир», листайте карточки лайками и дизлайками, проверьте совпадения с друзьями.
5. **Сравнение**: добавьте 2-3 квартиры в избранное и откройте «Сравнение».

## 5. Как заменить текущий фронтенд на сторонний

Бэкенд полностью автономен и не привязан к текущему React-интерфейсу. Любой фронтенд (React, Next.js, Vue, Nuxt, Svelte, мобильное приложение на Flutter/Swift или Telegram Mini App) может взаимодействовать с бэкендом через стандартные REST API запросы.

### 1. Настройка CORS
В `backend_fastapi/main.py` уже настроен `CORSMiddleware` с `allow_origins=["*"]`, что разрешает обращения с любых доменов и портов (например, `http://localhost:3001` или `http://localhost:5173`).

### 2. Основные REST API эндпоинты для вашего нового фронтенда:

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `GET` | `/api/listings?city=Красноярск&deal_type=rent` | Получить список всех спарсенных квартир с координатами и ссылками |
| `POST` | `/api/search?query_text=...` | Поиск на естественном языке с Gemini-нормализацией |
| `POST` | `/api/tinder/filter` | Случайная выдача карточек для свайп-механики Тиндера |
| `POST` | `/api/parser/avito/run?city=Красноярск&deal_type=rent` | Принудительный триггер парсера Авито |
| `GET` | `/api/analytics/real-sources` | Данные Генплана Красноярска и льготных ипотек |
| `POST` | `/api/auth/register` | Регистрация пользователя |
| `POST` | `/api/auth/login` | Вход пользователя |
| `POST` | `/api/friends/add` | Добавление друга по username |

### 3. Автогенерация типизированного клиента
Вы можете экспортировать готовую спецификацию OpenAPI и за 1 секунду сгенерировать TypeScript SDK:
```bash
# 1. Скачать схему
curl http://127.0.0.1:8000/openapi.json > openapi.json

# 2. Сгенерировать TypeScript клиент для нового фронтенда
npx openapi-typescript-codegen --input openapi.json --output ./src/api-client
```

После этого в вашем новом фронтенде можно делать вызовы в одну строчку:
```typescript
import { ListingsService } from './api-client';

const { listings } = await ListingsService.getListings('Красноярск', 'rent');
```
