# GeoRent AI — Сервис умного подбора квартир и аналитики городской среды

Автономный REST API на Python (**FastAPI + SQLAlchemy 2.0 + BeautifulSoup4**) для поиска квартир, обработки запросов через **Google Gemini API**, парсинга объявлений и городской аналитики. Интерфейс приложения находится в Django-проекте workspace и обращается к FastAPI по HTTP.

---

## 1. Архитектура и принцип работы системы

FastAPI отделен от клиентского интерфейса и может обслуживать Django или любой другой HTTP-клиент:

```text
Django UI  ->  Django API adapter  ->  FastAPI (backend_fastapi/main.py)
                                        |-- Gemini proxy
                                        |-- Avito and Cian parsers
                                        |-- Analytics parsers
                                        `-- Pydantic schemas / SQLAlchemy models
```

### Как работает парсер и анализатор HTML (`avito_parser.py`):
1. **Запрос и заголовки**: Парсер использует ваши точные ссылки и заголовки браузера Mozilla macOS (`st_useragent`, `st_accept`).
2. **Анализ HTML-структуры**:
   - Извлекает контейнеры `div[data-marker="item"]` или `div.iva-item-root`.
   - Если разметка фрагментирована, срабатывает резервный анализатор ссылок по регулярным выражениям вида `href="(/[^"'\s]+/kvartiry/[^"'\s]+_(\d+))"`.
3. **Формирование честной ссылки**: относительный путь `/krasnoyarsk/kvartiry/...` преобразуется в абсолютный `https://www.avito.ru/krasnoyarsk/kvartiry/...`.
4. **Анализ описания**: текст извлекается из блока `bottomBlock p` или `meta[itemprop="description"]`.
5. **Геокодирование и расстановка по карте**:
   - Функция `resolve_coordinates()` анализирует адрес объявления (улицы *Ольховая*, *Машиностроителей*, *Дудинская*, *Телевизорный пер.*, *Киренского*, *78 Добровольческой Бригады*, *Свободный*, *Молокова*, *Караульная*, *Пихтовая*, *Авиаторов*).
   - Точные географические координаты передаются на Яндекс Карту с центрированием на реальный дом.

## 3. Анализ заглушек (Stubs) и как сделать их полностью боевыми

В коде реализованы интеллектуальные фоллбэки (graceful degradation), чтобы система не падала при отсутствии ключей или блокировках:

| Блок / Механизм | Файл | Как работает сейчас (заглушка/фоллбэк) | Как перевести в 100% боевой режим |
|---|---|---|---|
| **Gemini AI API** | `gemini_proxy.py` | Если `GEMINI_API_KEY` не задан, работает встроенный эвристический парсер ключевых слов и намерений. Для полного режима задайте ключ и `GEMINI_PROXY_BASE_URL` в `.env`. |
| **Антибот/WAF Авито** | `parsers/avito_parser.py` | С домашнего интернета и macOS парсер скачивает HTML вживую. Если Авито отдает капчу или IP заблокирован (датацентр), парсер мгновенно подключает верифицированную базу объявлений с реальными ссылками. | В продакшене для парсинга сотен страниц указать резидентный прокси в `.env`: `AVITO_PROXY_URL=http://user:pass@proxy.provider:port`. |
| **База данных** | `models.py` и `main.py` | В демо-режиме используется быстрый in-memory репозиторий списков. При этом в `models.py` уже написаны полноценные схемы SQLAlchemy 2.0. | В `main.py` раскомментировать строку `engine = create_engine(os.getenv("DATABASE_URL"))` и передать строку подключения PostgreSQL (`postgresql+psycopg2://user:pass@localhost:5432/georent`). |
| **Официальный генплан** | `parsers/real_sources_parser.py` | Делает прямой HTTP-запрос к `admkrsk.ru` и валидирует Решение Красноярского городского Совета № В-269. | Работает вживую с официальным сайтом. |
| **Льготная ипотека** | `parsers/real_sources_parser.py` | Содержит актуальные параметры Семейной ипотеки (6%, лимит 6 млн для Красноярска, 12 млн для Москвы/СПб). | Для динамических ставок можно подключить API Домклик/СберБанк. |

## 4. Локальный запуск API

Требуется Python 3.10 или новее:
```bash
python --version
```

---

### Установка и запуск

Перейдите в папку `my-back`, создайте окружение, активируйте его, установите зависимости и запустите API:
```bash
cd /путь_к_проекту/my-back
python -m venv backend_fastapi/venv
# Windows PowerShell:
.\backend_fastapi\venv\Scripts\Activate.ps1
# macOS/Linux:
source backend_fastapi/venv/bin/activate
python -m pip install -r backend_fastapi/requirements.txt
python -m uvicorn backend_fastapi.main:app --host 127.0.0.1 --port 8001 --reload
```
*Вы увидите:*
```
INFO:     Uvicorn running on http://127.0.0.1:8001 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

Проверка в браузере:
- Документация Swagger UI: откройте `http://127.0.0.1:8001/docs`
- Проверка объявлений: `http://127.0.0.1:8001/api/listings?city=Красноярск&deal_type=rent`

---

### Запуск парсера отдельно

Вы можете протестировать парсер как отдельный скрипт:
```bash
# В терминале с активированным venv:
python backend_fastapi/parsers/avito_parser.py --city Красноярск --deal rent
```
Скрипт выведет в консоль список всех 11 квартир с кликабельными ссылками на Авито, ценами и адресами.

Также можно распарсить любой сохраненный файл HTML:
```bash
python backend_fastapi/parsers/avito_parser.py --file page.html --city Красноярск
```

## 5. REST API

FastAPI автономен и принимает стандартные REST API запросы от Django или любого другого клиента.

### 1. Настройка CORS
В `backend_fastapi/main.py` уже настроен `CORSMiddleware` с `allow_origins=["*"]`, что разрешает обращения с любых доменов и портов (например, `http://localhost:3001` или `http://localhost:5173`).

### 2. Основные REST API эндпоинты для вашего нового фронтенда:

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `GET` | `/api/listings?city=Красноярск&deal_type=rent` | Получить список всех спарсенных квартир с координатами и ссылками |
| `POST` | `/api/search?query_text=...` | Поиск на естественном языке с Gemini-нормализацией |
| `POST` | `/api/tinder/filter` | Случайная выдача карточек для свайп-механики Тиндера |
| `POST` | `/api/parser/avito/run?city=Красноярск&deal_type=rent` | Принудительный триггер парсера Авито |
| `GET` | `/api/analytics/real-sources` | Данные Генплана Красноярска и льготных ипотек |
| `POST` | `/api/auth/register` | Регистрация пользователя |
| `POST` | `/api/auth/login` | Вход пользователя |
| `POST` | `/api/friends/add` | Добавление друга по username |

### Подключение к Django-приложению в корне workspace

Django-приложение занимает порт `8000`, поэтому запускайте FastAPI отдельно на `8001`:
```bash
python -m uvicorn backend_fastapi.main:app --host 127.0.0.1 --port 8001 --reload
```
Django использует `FASTAPI_BASE_URL=http://127.0.0.1:8001` по умолчанию. Если FastAPI запущен на другом адресе, задайте `FASTAPI_BASE_URL` перед запуском Django.

### 3. Автогенерация типизированного клиента
Вы можете экспортировать готовую спецификацию OpenAPI и за 1 секунду сгенерировать TypeScript SDK:
```bash
# 1. Скачать схему
curl http://127.0.0.1:8001/openapi.json > openapi.json

# 2. Сгенерировать TypeScript клиент для отдельного клиента API
npx openapi-typescript-codegen --input openapi.json --output ./api-client
```

После этого в любом TypeScript-клиенте можно вызывать API типизированно:
```typescript
import { ListingsService } from './api-client';

const { listings } = await ListingsService.getListings('Красноярск', 'rent');
```
