# GeoRent AI — FastAPI Backend & Database Architecture

Полнофункциональный бэкенд на Python / FastAPI для сервиса умного поиска и аналитики недвижимости с интеграцией Google Gemini через Proxy-слой.

## Структура базы данных (SQLAlchemy 2.0)
База данных спроектирована со всеми обязательными метками и аналитическими сущностями:
1. `UserPreferences` — Предпочтения пользователя (бюджет, тип сделки, школы, метро, ипотека, push-токен)
2. `DistrictLocation` — Район и локация (рейтинги безопасности, экологии, транспорта, средние цены)
3. `NewDevelopment` — Новостройки (девелоперы, класс жилья, эскроу, срок сдачи, рейтинг ЕРЗ)
4. `PreferentialMortgage` — Льготные ипотеки (Семейная 6%, IT-ипотека, первоначальный взнос, лимиты)
5. `RentalMarket` — Рынок аренды (медианные ставки, динамика MoM/YoY, срок экспозиции, yield)
6. `GeoData` — Геоданные (координаты, полигоны, ближайшие станции метро, рейтинговые школы ТОП-100, парки)
7. `MasterPlan` — Генеральный план (зоны КРТ, реновация, запланированные дороги и мосты до 2035 г.)
8. `OpenData` — Открытые данные (статистика МВД, качество воздуха Мосэкомониторинг, кадастр)
9. `DistrictAnalysis` — Анализ района (плюсы, минусы, вердикт ИИ, семейная пригодность)
10. `FutureInfrastructure` — Будущая инфраструктура (новые станции метро, школы, больницы с влиянием на цену)
11. `NewBuildingComparison` — Сравнение новостроек (отделка, риски срыва сроков, инвестиционный ROI)
12. `BuyVsRentAnalysis` — Покупка vs аренда (расчет окупаемости, доходность депозита против ипотеки)
13. `RentCloserVsFarther` — Аренда ближе/дальше (экономия на аренде против времени и расходов на транспорт)
14. `ExplanationAndSources` — Объяснение и источники (цитаты ЕИСЖС, data.mos.ru, генплана)
15. `Report` — Отчёт (полное резюме, риски, ипотечный сценарий)
16. `Uncertainty` — Неопределённость (оценка волатильности ставок ЦБ, задержки ввода, сезонность)
17. `Listing` — Глобальная база объявлений (от собственников и спарсенных с Авито/Циан/Домклик)
18. `UserLocalComparison` — Локальная БД пользователя для сравнения выбранных объектов
19. `ScheduledSearch` — Killer feature: Автопоиск по расписанию (раз в 1-2 дня)

## Запуск FastAPI приложения

```bash
cd backend_fastapi
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt

# Настройка переменных окружения
export GEMINI_API_KEY="your-gemini-api-key"
# Если доступ из России — задайте адрес прокси или ProxyAPI:
export GEMINI_PROXY_BASE_URL="https://api.proxyapi.ru/google/v1beta"
# Или системный HTTP прокси:
# export HTTP_PROXY="http://user:pass@proxy.example.com:8080"

uvicorn backend_fastapi.main:app --reload --port 8000
```
Swagger документация будет доступна по адресу: `http://localhost:8000/docs`
